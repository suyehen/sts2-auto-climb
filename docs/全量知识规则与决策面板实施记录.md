# 全量知识规则与决策面板实施记录

日期：2026-10-11。目标保持为全量卡牌、药水、遗物计算支持；本记录不能视为目标已经完成。

## 已落地的基础设施

- `data/knowledge/catalog/`：百科资料、原子替换和历史回滚。
- `data/knowledge/rules/`：受限制的可执行规则与待核验提案。
- `data/knowledge/coverage/`：完整源码类清单、逐条百科与源码核对结果。
- `data/knowledge/events/`：事件转移规则与实际公开状态观测。
- `data/decisions/live/`、`replay/`：完整决策记录；实战与离线回放分开。
- `src/web/public/`：本地只读决策面板。
- `src/python/src/autoslay/dashboard/`：面板 HTTP 服务，游戏凭据只留在服务端。

规则解释器从结构化数据读取有序效果，不再在卡牌登记函数里维护名称白名单。原导入名 `IroncladRules` 保留为兼容别名，实际实现为 `KnowledgeRules`。

## 百科更新

C# 0.22.0 已构建：使用 `ModelDb.AllCards/AllPotions/AllRelics`，覆盖锁定和生成内容；导出模型类型、动态变量和游戏程序集 SHA256。它们不是奖励可选池，旧内容和测试模型需要在覆盖清单中区别处理。

规则同时绑定游戏版本、参考条目指纹和当前游戏程序集。资料变化不会自动批准新规则。决策缓存包含知识和规则指纹；一般决策报告只附本次涉及条目的兼容状态，完整清单通过面板或专门查询读取。

## 面板

地址：`http://127.0.0.1:18767/`。

启动：`launch/Start-DecisionDashboard.ps1`，或使用项目虚拟环境执行 `src/python/tools/runtime/decision_dashboard.py`。实时分析需要常驻服务 `src/python/tools/runtime/execution_service.py`。

第一版展示输入、生命/能量/手牌、逐步状态变化、自损与受击预测、伤害、格挡、星星、候选、分项、搜索预算、概率情境、事件连续路线、AI资料建议包、实际分析报告、选择意图及执行证据、原始快照和版本。

可分析已有公开状态回放、浏览历史、导出 JSON；不会出牌、购买、选择事件或开启自主策略。API 检查 Host、Origin 和自定义只读请求头，不开放 CORS；页面采用 textContent 显示游戏文字。

## 连续事件

已实现通用有限转移图：明确状态、选项、结果概率、效果、下一状态和终止；预算截断保持未知，不将循环外收益假设为零。

已核对深渊浴场游戏实现：首次增加最大生命 2，同时回复对应生命，再造成伤害 3；每次伤害增加 1。首次放弃回复 10，进入后的退出不回复。页面文字索引最多到 9，但伤害并不因此停止增长。

面板报告立即结束与继续若干次后结束的生命、上限、收益和过程。最大生命权重暂为 1 分/点，未经实战校准。拥有会影响事件生命的遗物或状态时，未适配钩子会阻止该事件的数值断言。

实际事件页面自动按会话、运行、楼层、状态版本和内容去重保存。观测不是已选择动作或普遍转移规则的证据，不能据一次观测外推未知阶段。

本次基础适配后，参考指纹兼容条目为卡牌 54、药水 11、遗物 17。**兼容也不等于所有效果及交互已经完整模拟。** 触发遗物、各角色专有资源、复杂卡牌、其余药水、状态触发链与长期评价仍需继续适配。全量验收未通过，不能宣布完成。

药水与卡牌共用有序效果引擎；已接入格挡、能量、力量/临时力量、易伤、直接伤害/群体伤害、抽牌、复合能量后抽牌和当前格挡倍增。虚弱效果只支持观察边界，不能据此声称完整数值模拟。直接伤害按游戏的 Unpowered 规则不受力量和易伤加成，但仍受伤害上限和格挡影响；格挡药水不消耗 Pael's Legion 的卡牌格挡增益。抽牌药水不会将手中牌移出，满手或禁止抽牌时保持牌堆组成。

新版导出新增模型类型及药水/遗物动态变量。仅在原有语义字段全部相同且此前规则固定的程序集指纹与游戏一致时，可显式运行 `src/python/tools/kb_admin/rebind_export_metadata.py --previous 历史文件` 迁移引用指纹；游戏更新或数值改变会拒绝迁移。此入口保留验证级别，不批准新机制。

`src/python/tools/kb_admin/audit_full_knowledge.py --write-proposals` 为全量条目生成核对报告和提案；未知逻辑保持 pending，不能自动升级为验证通过。

`src/python/tools/kb_admin/review_rule_proposals.py ENTITY_ID ...` 只接受明确指定且符合受限制直线语法的源码提案，并固定出处；条件、触发、费用属性或生命周期未识别时拒绝。源码核对与合成流转检查分别记录，不能代替真实游戏验证。
