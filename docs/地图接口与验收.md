# 地图接口与验收

0.5.0 适配本机游戏 v0.111.0，支持单人当前幕地图读取和单节点选路。已部署，33 项 C# 与 9 项 Python/MCP 检查通过，真实地图读取、选路与转场验收通过。

## 状态与决策

`state.map` 包含 open、active、decision_ready、act_index、generation、current_position、visited 和 nodes。每个节点提供坐标、类型、状态、是否已访问、当前是否可走、action_id 和 children。仅导出当前打开地图所呈现的节点与连接；未知房间仍为 Unknown，不读取未来幕、隐藏遭遇或随机数。

Codex 根据血量、牌组、资源及路径自行选择。模组不内置选路策略。暂停时节点仍可观察，但不提供可执行动作。

## 执行

从 `legal_actions` 选择 type=`choose_map_node` 的 action_id，使用新快照的 command_context_id、session_epoch、state_version，target_id=null。调用游戏原有 OnMapPointSelectedLocally，将地图投票动作交给正常同步和转场流程。一次请求只选择一个节点。

派发前检查单人、地图为活动界面、旅行开关、节点 Travelable/Enabled、队列空闲、无转场、无绘图、无教程阻塞及地图生成编号匹配。调试自由旅行不支持。

completed 要求到达目标坐标、层数前进、房间对象改变、地图关闭、旅行和转场结束、队列空闲且新房间就绪。单纯坐标变化或投票入队不足以完成。弹窗或 45 秒未完成返回 needs_user_input，保留执行槽；应查询原 request_id，避免重复旅行。同 ID 重试返回已有回执。

## 验收

自动测试涵盖非相邻节点、调试旅行、绘图、初始教程、坐标先更新、转场尚未完成、教程弹窗和对局替换。真实验收：读取 68 个节点及连接，当前位置 (1,1)，唯一合法节点为 (0,2) 的 Unknown。非相邻节点 (6,2) 返回 INVALID_ACTION，旧版本返回 STALE_STATE，均 dispatched=false 且状态完全未变。选中 (0,2) 后层数 2→3，活动界面进入 NEventRoom，地图关闭，回执 completed、busy=false；重复原 request_id 返回完全相同回执，状态版本与层数未再变化。控制随后暂停，HP 57/80、金币 112、牌组 12 张。证据保存在 .runtime/logs/map-live-verification.json 与 map-negative-verification.json。

商店、事件、篝火和宝箱的房间内操作尚未实现；进入这些房间不代表可自动完成其后续选择。跨幕、Boss 与初始地图教程尚未实测。
