# 本地事件、怪物与意图资料

全部以本机游戏导出及游戏源码为基准，不再使用 Wiki。静态资料在 `data/knowledge/behavior/catalog.json`，卡牌、药水、遗物仍在原游戏百科文件中，互不覆盖。

当前游戏 0.111.0：57 个事件、119 个怪物实体、14 类意图。怪物数量包含部位、生成物和测试实体。抽象父类不作为独立怪物，具体部位继承的行动及参数保留父类来源证据。

事件记录中文阶段文本、选项说明、处理方法证据及流程提示。Agent 上下文与 MCP 查询省略剧情描述，网页保留折叠的剧情。固定卡牌、药水、遗物占位符关联实际 entity_id；熔合者的究极打击、防御已关联原百科，Agent 会附带对应卡牌效果。随机或随局变化的实体应使用实时选项的卡牌悬浮信息，不能把静态候选误认为本次已生成结果。

怪物行动图记录全部条件/随机分支、目标行动、条件优先顺序、构建时条件、随机权重、连续使用上限、冷却限制和初始行动选择证据。怪物生命周期方法、强制换行动方法、状态变量及状态更新，以及相关 buff 的中文说明、数值变量、叠加类型和触发方法也保存在本地。保留完整源码证据供复杂机制查询；这些资料不会自动注册为 Python 模拟器规则。

## 怪物数值

进阶门槛从当前游戏的 AscensionLevel 枚举读取，不写死为网页规则。此版本进阶 8 提高部分初始生命，进阶 9 提高部分行动数值。例如多尼斯异鸟：进阶 0–8 啄击 3×3、飞扑 17；进阶 9–10 啄击 4×3、飞扑 19。生命在进阶 0–7 为 81–84，进阶 8–10 为 90。

行动资料包含基础伤害、攻击次数、总基础伤害，以及从处理方法提取的格挡和状态层数。数值提取只支持明确常量、属性引用、加减乘和游戏进阶切换，不执行任意 C#。依赖当前生命、复活次数、力量、玩家目标状态及未支持表达式的数值标为动态，绝不填零。部分处理方法有条件分支，提取到的效果不是保证全部发生；源码仍标记为待核验参考。战斗实时意图包含力量、虚弱等修正后的数值，应优先用于当前回合计算。

这些资料可供 Agent 按当前敌人和事件查询；行为资料预算 64 KB，并保留总上下文预算。只附带相关实体和所需机制证据，不传整套游戏源码。可通过 MCP query_behavior_log 按需读方法证据。收录静态数值不会自动启用新的模拟规则或自动执行资格。

## 怪物图标

`data/knowledge/assets/monsters/` 保存本地 WebP 和构建绑定的 manifest.json。目前 113 个实体有图像，6 个无独立图像的隐藏或测试实体会明确显示缺图，不用其他怪物替代。原游戏的占位图也保留其原样。大多数图像使用游戏原生 Spine 资源渲染，保留透明背景，避免把贴图图集当成完整怪物。预览是静态主视觉，不包含场景粒子及额外挂载的动画特效。

导出器创建独立图片资源包，仅加载游戏安装目录的 Spine 渲染库，不加载游戏脚本、存档、FMOD 或 Sentry。使用游戏引擎的 OpenGL 渲染能力，不需要启动对局。

导出会读取游戏 SetupSkins 的固定皮肤、组合皮肤和额外动画轨道；随机外观使用一个合法的代表组合。启用恐惧替代皮肤的模型使用普通 normal 外观，修复化石追踪者预览 Default 皮肤仅显示肢体的问题。使用的皮肤记录在图像 manifest 中。

## 更新入口

先更新原游戏百科，然后运行：

```powershell
.runtime/conda/python.exe src/python/tools/knowledge/export_behavior.py
.runtime/conda/python.exe src/python/tools/knowledge/export_monster_portraits.py
```

工具支持 --game-path 指定安装目录。行为导出从 PCK 读取中文资料，使用 ILSpy 解编译当前 DLL。源码缓存绑定程序集 SHA-256；原百科与当前游戏构建不一致时拒绝更新。候选行为库完整验证后原子替换，同级 history 保存旧版。图标 manifest 绑定同一构建，网页不展示构建不匹配的图标。

知识资料更新和当前战斗状态读取独立。UI 默认显示中文数值及具体分支，工程视图可查看实际查询 JSON；来源、版本和计算资格仍保留在数据中，普通页面不反复展示声明。只有卡牌有类型筛选，事件、怪物和意图不展示职业或稀有度。分类栏支持宽屏六列、窄屏三列。
