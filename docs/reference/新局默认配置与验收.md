# 新局默认配置（0.16.0）

新增 MCP `start_new_run(request_id, character="IRONCLAD", ascension=None)`，以及 `src/python/tools/game/start_new_run.py`。依次执行主菜单单人游戏、标准模式、选择角色、调整进阶、出发；已经处于模式或角色选择界面时从当前步骤继续。未指定角色默认铁甲战士，支持 `铁甲战士`、`IRONCLAD` 和 `CHARACTER.IRONCLAD`；其他角色使用界面实体 ID。

进阶省略时，先选好角色，再读取该角色的 `max_ascension`，逐级调整到最高已解锁难度。可用 `--ascension 0` 等参数明确指定；超出解锁范围会停止，不会静默替换。

```powershell
./.runtime/conda/python.exe src/python/tools/game/start_new_run.py
./.runtime/conda/python.exe src/python/tools/game/start_new_run.py --character 铁甲战士 --ascension 0
```

每次动作都使用新的状态版本、会话及菜单上下文，派发前持久化请求到 `.runtime/logs/new-run-<request_id>.json`。同一 setup ID 重调用只返回记录，不再执行；参数不同会拒绝。回执不确定时立即停止，记录 `pending_request_id`，用 `get_action_status` 查询原请求，不换 ID 重开。结束时暂停，第一房间的选项留给后续决策。

未完成存档阻止新局入口。0.16.0 增加独立 `abandon_run` 单步动作，在稳定主菜单且存在存档、原放弃按钮可用时才提供；调用 `NMainMenu.AbandonRun()`，等待 `HasRunSave` 变为 false。该动作结束旧局，必须有用户放弃或替换旧局的授权，不能用于普通续档或自动重启。新局入口不调用该动作，也不操作存档文件。

验证：15 项 Python/MCP 测试通过，涵盖角色选择后的最高进阶、显式 0 进阶、不可用角色/进阶、已有存档保护、派发前日志及不确定出发回执的防重放；C# 回归检查全部通过，桥接构建零警告零错误。
