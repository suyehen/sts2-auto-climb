# 篝火接口与验收

0.9.0 针对游戏 v0.111.0 的标准 NRestSiteRoom 实现，代码位于 src/csharp/bridge/Commands/RestCommands.cs。构建零警告零错误，既有 54 项 C# 与 9 项 Python/MCP 回归检查通过；已部署并通过真实锻造与离开流程验收。

state.rest_site 提供界面实例、decision_ready、当前 options 以及 proceed_action_id。选项包含游戏实际 option_id、动态标题和描述、supported、available 和 action_id。读取当前界面已有选项，不重新生成选项或读取随机数。

choose_rest_option 支持休息（HealRestSiteOption）和锻造（SmithRestSiteOption）；proceed_rest 返回地图。使用已有请求协议，target_id=null，动作必须来自 legal_actions。单人、活动界面、队列空闲、无模态和转场、选项动画结束且按钮可用时才允许提交。额外遗物提供的篝火选项当前只读，不自动选择。

选择调用普通按钮使用的 NRestSiteButton.SelectOption 异步例程，进入正常游戏同步、效果及钩子。休息需任务成功结束且下一个篝火决策点就绪才完成。锻造打开受支持的升级选择器后，原请求 completed 仅代表选择器就绪，升级由后续选择、预览和确认动作完成；pendingSelectionEffects 等待父任务。确认后需回到稳定的篝火或其他受支持界面，才继续操作。

返回地图需当前地图活动且允许旅行。任务失败或取消返回失败；教程模态、未支持的选择流程或等待超时返回 needs_user_input，并保留执行槽供查询，不重新派发。
