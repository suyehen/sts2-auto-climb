# 当前战斗出牌决策规则说明

核对日期：2026-10-15  
用途：记录当前实际生效的出牌决策，作为后续调整的讨论与实现依据。  
范围：本地配置、战斗搜索、评分、选牌、执行边界及备用策略。本文记录实现现状，不代表最优策略或安全证明。

## 1. 当前模式与配置来源

当前主要使用**本地操作批次搜索**：枚举连续操作，预测当前回合与下一回合的结果，优先比较预计死亡风险，再比较综合收益；分数接近时，优先省药、少掉血、减少近似。

配置读取顺序：

1. 读取 `config/decision/*.default.json`。
2. 若 `.runtime/local/agent/profiles.json` 存在对应 `decision` 配置，则合并本地覆盖。

本次核对时，本地战斗相关配置与默认配置一致。

| 设置 | 当前值 | 实际作用 |
|---|---|---|
| `deterministic_enabled` | `true` | 允许本地规则和搜索选择动作 |
| `combat_batches_enabled` | `true` | 启用当前主要战斗策略 |
| `strategy_mode` | `off` | 关闭校准收益区间策略 |
| `complex_strategy_enabled` | `false` | 对应功能未实现，开启会报错 |
| `require_fresh_action_validation` | `true` | 执行前检查新状态 |

批次模式允许搜索不完整、机制存在未知或预算耗尽时使用近似评分；独立校准不是执行前置条件。

正常代理流程中，批次模式未能产生可执行选择时，等待并重新分析，不自动切换给大模型决定战斗出牌。

## 2. 决策流程与前置条件

```text
读取实际状态
  → 检查连接、就绪、暂停、身份与源码认证
  → 处理战斗嵌套选牌或可直接执行的严格规则
  → 分析当前战斗
  → 生成操作批次
  → 预测批次之后的敌人行动、抽牌和后续操作
  → 按死亡概率和综合收益排序
  → 在接近分数候选中进行资源取舍
  → 获取新状态并复核
  → 逐步执行批次
  → 到观察边界、状态不匹配或批次结束时重新决策
```

以下情况先等待，不出牌：

- 游戏未连接、未就绪、正在忙碌、存在错误或用户暂停控制。
- 缺少会话、状态版本或本局身份。
- 游戏版本或程序集无法通过当前源码认证。
- 没有合法操作，或战斗选牌界面尚未准备好。

如果唯一合法操作是结束回合，可以直接结束回合。经过严格认证、没有回血或永久成长等资源取舍的一步斩杀，也可能在完整分析前走快速路径。

完整报告产生后，批次选择分支优先于后面的旧策略和严格比较分支。不能将所有保留在代码中的规则视为依次覆盖批次结果。

## 3. 候选操作和目标

候选包括：

- 当前合法的出牌动作及每个合法目标。
- 当前合法的药水动作及每个合法目标。
- 结束回合。

主动丢弃药水、退出游戏和返回主菜单不参与批次比较。

不存在固定的能力牌、技能牌、攻击牌优先级，也不存在统一的最低血量敌人优先级。出牌顺序与目标由模拟后的结果决定。

例如，攻击→攻击、格挡→攻击、力量→攻击、药水→攻击、抽牌后观察、直接结束回合，均可能形成不同候选。

同一序列的中间状态也能成为批次候选，因此无需用光能量或打完所有可用牌。

搜索会去重等价终点；忽略可互换卡牌实例的身份差异，避免占用多个 Top-K 位置。同等终点通常保留较短路径。去重并不保证每个合法首步都单独占据候选槽位。

## 4. 搜索预算与预测范围

### 4.1 普通与危险状态

| 参数 | 普通 | 危险 |
|---|---:|---:|
| 节点预算 | 2000 | 6000 |
| 批次搜索时间预算 | 200 ms | 400 ms |
| Top-K | 5 | 5 |
| 最大批次操作深度 | 6 | 6 |

满足任一条件进入危险状态：

- 当前生命 / 最大生命 ≤ 0.35。
- 可见敌人攻击总量 ≥ 当前生命。
- 当前地图节点为 Boss。

危险判断没有先扣除玩家格挡，精英战本身也不会直接触发危险预算。

### 4.2 批次后续预测

| 参数 | 当前值 |
|---|---:|
| `analysis.strategy.horizon` | 2 |
| `branches` | 32 |
| `seed` | 42 |
| `draws` | 5 |
| `energy` | 3 |
| `extra_budget_enabled` | false |
| `outcome_limit` | 128，当前不是批次分析器的直接限制项 |

预测跨度包含当前玩家回合与下一玩家回合。支持的周期遗物可以修正后续抽牌和能量。

批次生成最多使用约 40% 的时间预算和约一半节点预算，再对终点进行后续预测。假想后续的回合内深度受 `min(5, max_depth)` 限制。预算耗尽时使用快速估值，因此并非所有候选都完整算到第二回合末尾。

`analysis.lookahead` 是另一个报告分析模块的设置，不应与批次分析器实际使用的 `analysis.strategy` 混淆。

## 5. 最终排序与接近分数取舍

### 5.1 第一轮排序

按以下顺序比较：

1. 预计死亡概率更低。
2. 综合分数更高。
3. 近似次数更少。
4. 批次操作数量更多。
5. 批次 ID，作为稳定排序依据。

正常预测路径下，高分不能抵消更高的预计死亡概率。这里的概率来自模型、分支和近似，不是经过校准的真实死亡概率。

### 5.2 第二轮取舍

在前 5 名中，筛选：

- 预计死亡概率与第一名完全相同。
- 综合分数与第一名相差不超过 `tie_margin = 1.0`。

然后重新按以下顺序选一个：

1. 消耗药水数量更少。
2. 预计最坏掉血更少。
3. 近似次数更少。
4. 批次操作数量更多。
5. 批次 ID。

因此最终执行者不一定是最高分方案。例如不用药的方案只比用药方案低 0.8 分，且预计死亡概率相同，会优先不用药。

接近分数取舍比较药水数量，不直接比较瓶种；瓶种价值已经在综合评分中扣除。偏好更长批次也只是靠后的排序项，不是无条件多出牌。

## 6. 综合评分

```text
综合分数
= 本局生命资源价值变化
+ 预测范围外的未来失血价值
+ 战斗胜利奖励
- 存活敌人剩余生命惩罚
- 牌堆污染惩罚
- 消耗药水的保留价值
- 未知机制惩罚
- 死亡惩罚
```

| 项目 | 当前计算 |
|---|---|
| 生命资源 | 使用第 7 节非线性函数 |
| 远期压力 | 使用第 8 节能力代理，折半计价 |
| 胜利 | `+50`，来自 `short_term.finish_weight` |
| 存活敌人生命 | 每点 `−0.4` |
| 污染 | 抽牌堆和弃牌堆中，键含 `SLIMED`、`DAZED`、`WOUND`、`STATUS` 的牌，每张 `−1` |
| 药水 | 每瓶扣一次保留成本 |
| 未知 | 被显式计入评分的未知单位，每个 `−3` |
| 死亡 | `−10000`，同时受死亡概率优先排序约束 |
| 敌人成长独立项 | 0 |
| 玩家成长独立项 | 0 |

正常批次评分没有独立的“伤害×1”或“格挡×1.5”项：伤害通过击杀、减少敌人行动、剩余生命和未来压力产生收益；格挡通过减少预测失血产生收益，过量格挡没有独立奖励。

力量通过模拟攻击及远期输出产生收益，独立成长项当前为零。各种警告会被记录，但不是每条警告都会一律扣 3 分。

## 7. 生命资源与地图机会

设 `h` 为生命、`M` 为最大生命、`r` 为生命保留比例、`R` 为休息机会权重：

```text
V(h) = 2 × [h − 3 × (M − h)³ / (3 × M²)]
       − R × max(0, M × r − h) / max(1, M × r)

生命收益 = V(预测后生命) − V(初始生命)
```

生命按 0 到最大生命截断。满血附近每失去 1 血的代价约从 2 分开始，低血时边际代价上升；低于保留线后追加惩罚。回血使用同一个函数。

地图估值：

- 检查未来最多 4 步可达节点，最多遍历 128 个节点。
- 最近可能休息点距离为 `d`。
- 精英或 Boss 压力 `p = max(1 / 距离)`，无对应节点时为 0。
- `r = min(0.7, 0.4 + 0.12 × p)`。
- 没有发现休息点：`R = 8`。
- 发现休息点：`R = 8 × (1 + 1/d)`。

例如下一步有精英时保留比例为 52%；下一步有休息点时休息权重为 16。当前公式使休息点越近，低于保留线的惩罚越大。

战后回血明确识别燃烧之血 6 点，并按最大生命截断。胜利方案的预测状态和比较基准都加入对应战后回血，避免将回血解释成可以免费损失生命。

## 8. 牌组能力与远期压力

优先使用完整牌组，无牌组数据才使用手牌。统计平均伤害、格挡、力量、抽牌、能量、攻击段数、能量需求、攻击比例、低费比例、回血文本、战后回血和未知卡牌。

这些统计并非全部直接参与远期压力评分。实际主要公式如下：

```text
利用率 u = min(1, 3 / max(1, 5 × 平均能量需求))
输出 D = max(1, [平均伤害 + 持续力量 × 平均攻击段数] × 5 × u)
防御 B = 平均格挡 × 5 × u

虚弱时 D ×= 0.75
脆弱时 B ×= 0.75

收尾回合数 = min(4, 存活敌人总生命及格挡 / D)
预计额外失血 = max(0, 当前敌方攻击总量 − B) × 收尾回合数
远期生命价值 = [V(扣除预计失血后的生命) − V(当前生命)] × 0.5
```

持续力量不包含临时力量。终点无敌方攻击时，会尝试查看一次已建模的非攻击动作后续，修正压力估计。

当前远期公式固定使用 3 能量、5 张牌和 0.5 折扣，没有直接复用未来回合设置，也没有完整的回血循环、无限连或复杂抽牌产能循环识别。

## 9. 药水价值

当前允许主动使用药水，通过保留价值与战斗收益比较。

| 药水 | 保留成本区间 | 批次实际使用的中点 |
|---|---:|---:|
| 火焰药水 | 8～20 | 14 |
| 格挡药水 | 6～14 | 10 |
| 能量药水 | 6～18 | 12 |
| 力量药水 | 8～20 | 14 |
| 未配置价值的药水 | 未知 | 20 |

- 当前持有同种药水超过一瓶，成本乘 0.75。
- 药水栏已满且界面明确有可领取药水奖励，成本再乘 0.5。
- 每瓶只扣一次；不预测未来掉落。
- 降低预计死亡概率优先于保留药水。
- 死亡概率相同、分差不超过 1 时，优先少用药。

批次模式使用中点，不使用校准区间支配规则。

## 10. 抽牌、分支和未知机制

抽牌分支少时精确计算，较多时固定种子采样。分支收益和死亡指标按概率加权，最坏失血取分支最大值；假想后续优先较低死亡指标，再优先高分。

实际抽牌后停止批次，观察真实手牌，不执行假想抽牌分支中的动作。

未知处理包括：

- 将隐藏能力、未覆盖交互和推断记录为假设。
- 第一回合若只有一个无条件初始动作，且攻击与可见意图一致，可推断敌人初始动作状态，并明确标记。
- 无法建模的合法首步尽量保留，按当前状态敌人回合预测加文本收益估值。
- 敌方行动建模失败，回退到可见攻击结算场景。
- 搜索预算耗尽，使用快速估值。
- 不因近似本身一律禁止行动。

预计死亡为零仅表示已有模型或近似没有预测死亡，不构成安全证明。

## 11. 文本估值与完全退化路径

| 内容 | 固定估值 |
|---|---:|
| 卡牌能量费用 | 每点 −1 |
| 伤害 | 每点 +1 |
| 格挡 | 每点 +1.5 |
| 抽牌 | 每张 +3 |
| 力量 | 每点 +3 |
| 回血 | 按生命函数增加 |
| 失去生命 | 按生命函数减少 |
| 药水起始分 | −20 |

通过正则匹配中英文描述，不能完整解释多段、条件、目标和复杂机制。以上常数独立于正常批次评分。

如果状态标准化失败，完全退回单步文本评分：每个候选只有一步，按文本分选最高者，死亡概率与最坏掉血为未知，不走正常死亡概率排序与接近分数取舍。

## 12. 战斗嵌套选牌

1. 等待选牌界面准备好。
2. 已选数量达到最低要求时优先确认。
3. 否则将每张候选牌作为单张手牌，用文本规则估值。
4. 提示包含 `discard`、`exhaust`、`移除`、`消耗`、`弃` 时，优先低分牌。
5. 其他提示优先高分牌。
6. 每次只执行一个选择动作，再观察。
7. 最低数量不是有效正整数时，按需要 1 张处理。

当前没有系统比较弃牌后的剩余手牌组合，也没有完整识别消耗收益或关键组件保留。

## 13. 批次执行与重新决策边界

执行前重新获取状态并核对分析来源，执行过程中每一步检查连接、就绪、暂停、会话、本局、战斗实例、游戏版本、合法动作和合法目标。

以下情况停止批次：

- 战斗结束、阶段或执行上下文变化。
- 结束回合、抽牌等观察边界或弹出选牌。
- 无法模拟效果、动作未完成或结果尚未确定。
- 预测与实际不匹配。
- 手牌描述、费用、附魔、最大生命等核对资源发生变化。
- 原定批次完成。

预测不匹配会记录对应实体模型降级，后续生成批次时在对应动作后设置观察边界。它不会禁止使用该牌或药水。

核对时 `.runtime/local/agent/combat-batch-models.json` 有以下历史降级记录：

- `CARD.SETUP_STRIKE`
- `CARD.STRIKE_IRONCLAD`
- `CARD.MOLTEN_FIST`

这些记录不代表本次重新验证了对应模拟实现，也不是永久静态规则。

## 14. 保留的其他策略与权重

| 策略 | 规则 | 当前关系 |
|---|---|---|
| 严格证明 | 确定斩杀、等价、支配、共同首步 | 部分可走快速路径；完整批次报告通常先采用批次选择 |
| 旧当前回合策略 | 斩杀优先，其次少失血，再比较启发分 | 保留代码，批次分支优先 |
| 校准短期策略 | 收益上下界、生存约束、后悔值 | 关闭 |
| 独立 lookahead | 后续回合报告 | 不等于批次最终选择器 |
| 遗物时机分析 | 延迟、计数等收益报告 | 不直接覆盖批次最终排序 |

旧当前回合启发分：

```text
伤害 × 1 + 有效格挡 × 1.5 + 持续力量增量 × 3 + 抽牌数 × 0
```

旧策略要求更完整的机制与搜索覆盖，排除预测死亡候选，通常保留药水，不处理永久成长取舍，并只执行首步。不能将这些限制套到当前批次模式上。

### 15.2 需要修改代码

- 死亡概率最高优先级，以及是否增加风险容忍度。
- 接近分数时省药与少失血的顺序。
- 是否继续偏好更长批次。
- 未知卡牌是否允许仅凭文本自动执行。
- 远期固定 3 能量、5 抽牌、4 回合上限和 0.5 折扣。
- 成长、回血循环、抽牌产能循环和复杂敌人估值。
- 弃牌与消耗时的剩余手牌组合分析。
- 污染识别、文本估值常数和未知药水默认成本。

建议先确定四项行为目标：允许为输出承受多少失血、药水应保守到什么程度、未知机制能否自动出牌、接近分数时是否偏好长批次。后续再据此修改权重和排序。
