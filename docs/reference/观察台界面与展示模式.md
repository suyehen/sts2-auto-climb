# 观察台界面与展示模式

新版工作台入口为 `http://127.0.0.1:18767/`。启动脚本使用系统默认浏览器打开。实时侧窗继续使用独立窗口，复用同一套中文解读组件。

## 页面与导航

- 实时观察：跟随当前局，显示生命、资源、当前分析、运行状态、地图和最近记录。读取分析与自动游玩是两个明确的按钮。
- 对局记录：按日期、职业、进阶和结果筛选；进入一局后按幕、地图版本、节点、到访和记录类型回看。历史页面不会被实时轮询切回最新局。
- Agent 管理：点击后端卡片立即切换并暂停；配置编辑与状态轮询分离，尚未保存的输入不会被刷新覆盖。开始游玩需单独点击。
- 百科与计算：查询本地全量百科，每次最多显示 100 个匹配结果。明确区分有百科资料与有兼容计算规则，避免把规则匹配解释为全部交互已支持。

## 普通视图与工程视图

第一次打开默认普通视图。使用中文名称说明方案、预计失血、有效伤害、格挡、资源、评分、概率、计算范围和执行理由。计算详情可展开逐步执行前后变化与评分权重。概率以百分比显示，评分不解释为胜率。

工程视图保留中文界面，并增加完整决策记录、原始状态、实际 AI 发送包（对应归档记录）、执行证据及公开配置的 JSON 检查器。可导出当前 JSON。密钥不回传页面。视图切换保留当前对局、幕次、节点和记录；选择会保存在当前浏览器中。

数据缺失显示“未记录”，未支持的收益不会补成零。尚无中文映射的内部错误码使用普通说明，原始信息在工程视图查看。

## 地图来源与导出

节点、连线、到达状态和当前位置读取游戏桥接数据。0.26.0 新增 `visual_position`，读取游戏实际布局坐标，包含游戏布局的偏移；旧归档保留原网格坐标回退。幕次由归档动态生成，不写死三幕。

网页采用可点击的 SVG 呈现地图，支持缩放、节点回看和 SVG 导出。导出的 SVG 是观察台绘制的交互地图，**不是游戏原生截图**。

游戏自身存在地图截图功能，但 Steam 版会交给 Steam 截图系统。当前没有调用该分享功能，也没有实现原生 PNG 导出；如需完全一致的背景、材质和房间图标，还需单独接入本地图片导出并进行游戏内验证。原生坐标字段已通过编译，实际游戏展示仍待下次启动游戏验证。

## 代码边界

- `workspace.js`：四个页面的路由、选择与请求状态。
- `presentation.js`：中文解读、候选方案与计算详情。
- `map.js`：地图几何、交互和 SVG 导出。
- `agent.js`：后端切换、配置编辑和运行控制。
- `sidebar.js`：实时侧窗与冻结观察。
- `workbench.css` / `sidebar.css`：完整页面与窄窗样式。

完整记录仍沿用 `data/runs/YYYY-MM-DD/本局目录`，百科仍位于 `data/knowledge`；本说明属于项目文档，不是知识库内容。
