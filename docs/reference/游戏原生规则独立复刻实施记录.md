## 2026-10-21 后续：Power 命令链、动态监听及共享缩放

`PowerCmd` 迁入泛型单体/多目标 Apply、实例 Apply、ModifyAmount、Decrement、TickDownDuration、两个 Remove 入口，以及原有叠加实例查找。`Hook` 保留 Before、给出方先加算再乘算、接收方顺序修正、修改后通知、After 的阶段。修改者在两个数值阶段都生效时，修改后通知仍按当前监听顺序每个模型调用一次。

保留并验证了原生细节：

- Artifact 使用原源类拦截负力量等 debuff，并通过嵌套 Decrement 消耗自身；已有能力的被拦截修改仍记录 amount=0 的 PowerReceivedEntry。
- 新能力被拦截后，泛型 Apply 仍可返回未挂到 owner 的新对象；不能根据旧注释把它改成 null。玩家 debuff 的首次持续时间递减会跳过一次。
- ModifyAmount 先截断 offset 再与当前 amount 相加，返回值可以高于 SetAmount 封顶后的实际值；小数 offset 的历史仍保存 decimal。溢出发生时保留此前自己分支中的历史前缀，并使分支失效。
