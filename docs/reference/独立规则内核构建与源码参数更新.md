## 清点和暂存

```powershell
& .runtime/tools/dotnet/dotnet.exe src/csharp/tools/RuleSourceSync/bin/Release/net9.0/RuleSourceSync.dll inventory .runtime/cache/game-source .runtime/analysis/independent-source-inventory.json
& .runtime/tools/dotnet/dotnet.exe src/csharp/tools/RuleSourceSync/bin/Release/net9.0/RuleSourceSync.dll dependencies .runtime/cache/game-source .runtime/analysis/independent-source-dependencies.json
& .runtime/tools/dotnet/dotnet.exe src/csharp/tools/RuleSourceSync/bin/Release/net9.0/RuleSourceSync.dll parameters .runtime/cache/game-source .runtime/analysis/independent-parameter-stage
```

`inventory` 是语法库存，记录字段、属性、事件、方法、来源哈希和语法调用。`dependencies` 用源文件和 .NET 框架做离线语义绑定，输出已解析的来源/框架调用、未解析调用、成员类型和全部错误诊断。没有加载原游戏程序集；因此缺失引擎、生成代码或第三方依赖的错误会保留。工具成功写出报告不代表依赖闭合。

`stage` 只替换命名空间。`parameters` 除命名空间外，将模型 `CanonicalVars` 中显式 `new *Var(...)` 的直接数值实参，以及 `OnUpgrade` 中 `UpgradeValueBy(...)`、`EnergyCost.UpgradeBy(...)`、`UpgradeStarCostBy(...)` 的直接数值实参，替换为模型实例的 `Parameters.Decimal(key)` / `Parameters.Int32(key)` 读取。当前工具版本 1.6.0，还绑定符合条件的直接 CardModel 构造费用及基础星数费用 getter，方式见下文。参数上下文由自有模型/世界及构造工厂提供；全目录暂存产物尚不能编译。

当前已编译模型使用下面的有限迁移单元入口：

```powershell
& .runtime/tools/dotnet/dotnet.exe src/csharp/tools/RuleSourceSync/bin/Release/net9.0/RuleSourceSync.dll units .runtime/cache/game-source src/csharp/rules/migration-units.json src/csharp/rules/Generated
```

`migration-units.json` 只选择要编译的源文件，不存效果。输出包含源码、编译行为/绑定常量、运行参数包和 `RuleUnits.props`。rules 项目排除 Generated 默认 glob，仅导入 props 活动文件。当前 39 个源单元包含 Injury/Dazed/Enlightenment、四个遗物、Artifact/Strength/Minion/NoEnergyGain 四个 Power 完整源类，以及完整 CardEnergyCost/局部费用类型、关键词/资源不足原因枚举、DamageResult、CardPlay/ResourceInfo、SingletonModel 等公共类型。另有多人缩放、临时力量、卡牌/牌堆/升级/星数/支付和能量命令的有限规则成员独立复刻代码。CanonicalVars 的单元素 DynamicVar、CanonicalKeywords 的 CardKeyword 单元素/数组编译器辅助集合转换为即时数组；条件、调用和规则顺序保留。其他未迁依赖仍编译失败，不替换成空方法。

PE 元数据和静态模型表可单独只读核对：

```powershell
& .runtime/tools/dotnet/dotnet.exe src/csharp/tools/RuleSourceSync/bin/Release/net9.0/RuleSourceSync.dll metadata ASSEMBLY_PATH OUTPUT.json
& .runtime/tools/dotnet/dotnet.exe src/csharp/tools/RuleSourceSync/bin/Release/net9.0/RuleSourceSync.dll roster ASSEMBLY_PATH .runtime/cache/game-source/MegaCrit.Sts2.Core.Models/AbstractModelSubtypes.cs OUTPUT.json
```

`metadata` 用 PEReader 读取类型、字段、方法和 IL 字节，不把输入加载成 CLR 程序集。`roster` 严格解析直接 typeof、数组槽位、字面量 Count 和完整类型名，与 PE 继承候选集合逐项比较；缺少/歧义类型报错，重复或集合差异输出报告并返回非零。它不执行 ModelDb/IsAllowed/构造器，不把包含 mocks/弃用类型的静态集合当作实机注册或支持分母。当前静态集合 1660 项一致；模组和注入仍未核验。

条件、循环、目标、变量类型、`PowerVar<T>` 的类型实参、`ValueProp` 和命令调用仍在 C# 中。除上述有限位置外的常量、计算表达式和非数值数据尚未外置；`parameter-scope.json` 列出已检查成员内未绑定的数值，以及 `constructor_cost_sites`、`canonical_star_cost_sites` 的绑定/缺口，并声明 `full_parameter_coverage=false`。它不声称枚举了所有其他成员中的数值。

构造器费用绑定要求非 partial、直接继承 CardModel、恰好一个 public 无参源构造器、直接 base 初始化器及 int32 字面量费用。生成器将构造器改为接收 `RuleParameters`，用该参数在 base 调用中读取数值，保留原构造体与求值顺序；参数名自动避开原类型标识符。ModelRegistry/ModelDb 通用工厂优先选择这个签名，否则使用原 public 无参签名；不靠 ID 表或全局世界传递上下文。构造器链/多构造器/间接常量保留原代码并列为缺口，未迁入的无参调用编译失败。工厂不通过构造后修补来纠正依赖旧费用计算出的私有字段。

生成器同时把数值包显式传入 CardModel/AbstractModel 的不可变构造上下文；构造体内读取参数化 CanonicalVars 或 CanonicalStarCost 时无需等待世界初始化。随后模型附着世界时核对同一参数对象，拒绝错配。基础星数费用仅绑定有上述构造上下文的直接 int32 override getter，支持表达式体或单条 return getter；复杂表达式、间接常量与无上下文类型保留代码并列缺口。这里仍不提供构造期间访问 ModelDb 或可变世界的能力。

本次全源码暂存为 2397 条绑定，含 596 个卡牌构造费用、22 个基础星数费用；PE 的 603 个 Card 静态候选中，余下 7 个是未绑定的 mock 子类。MockCardModel 的构造器与基础星数 getter 保留缺口，已检查变量/升级成员仍有 335 个未绑定数值节点。见 `.runtime/analysis/independent-card-parameter-audit-15.json`。这些数字仅表示数值抽取，不是模型已编译或支持率；当前运行包仅用下述七条。

工具先检查全部输出冲突，再写文件。修改过的生成文件或未受旧 manifest 管理的同名文件会导致停止覆盖。消失的源文件在 manifest 的 `obsolete_files` 和 `retained_obsolete_files` 中持续登记，保留磁盘文件；消费者必须按 manifest 的活动文件列表处理，不能用目录 glob 把陈旧文件编译回来。暂存输出与源目录必须分离。

## 参数身份与更新

`rule-parameters.json` 遵守 `contracts/rule-parameters.schema.json`。每条仅包含绑定键、数值类型/值和源码位置/哈希。它没有效果程序。整数必须在 int32 范围内且无小数；decimal 保留十进制精度。原生变量自身执行封顶和取整，不在参数包里提前截断。

三种身份分开：

- `source_fingerprint`：完整源码输入的身份。
- `behavior_sha256`：参数化后暂存源码的身份。只改已抽取实参的数值时不变；改条件、Props、类型或未抽取常量时变化。
- `contract_sha256`：全部绑定键和类型的身份。增删绑定或类型改变时变化。

加载参数时调用方必须给出编译产物期望的行为与绑定身份；不能直接把包里自报的身份当成编译身份。`RuleParameters` 还核对实际绑定条目、拒绝重复/未知字段，并对缺失参数或读取类型错误返回明确边界。它是可跨候选共享的不可变数据，变量本身仍属于各自模型实例。包的原始 SHA-256 随数值和来源数据变化，供后续缓存失效使用。

`CompiledRules.LoadDefaultParameters()` 加载自有程序集嵌入的有限参数包；`LoadParameters(bytes)` 用编译生成的常量验证外部包。当前仅含七个模型的七条绑定：四个遗物变量及 Injury/Dazed/Enlightenment 构造费用。全目录暂存包的 2397 条绑定不是当前运行合同。增加或改变迁移单元后先重新生成、构建、验证身份和语义；仅更新已绑定数值可保持相同编译行为合同。已验证同一 Injury 编译类改读新的费用，以及同一编译卡牌夹具在构造体内读到更新后的能量、星数费用和变量，再使用更新后的升级增量。

保留旧、新输出后比较：

```powershell
& .runtime/tools/dotnet/dotnet.exe src/csharp/tools/RuleSourceSync/bin/Release/net9.0/RuleSourceSync.dll compare-parameters OLD/rule-parameters.json NEW/rule-parameters.json
```

差异报告区分已抽取范围内仅数值更新、绑定变化需重新编译、行为变化需语义迁移。它不授予发布权限，也不免除回归。新实体仍须迁入自己的 C# 模型、闭合依赖并通过编译/语义/交互验证，不需要手写另一份效果 JSON。

## Host 当前协议

`contracts/rules-host.schema.json` 定义 JSON Lines 请求。Python `autoslay.rule_runtime.RuleRuntime` 用显式命令参数数组启动私有进程，可指定独立工作目录，支持常驻复用与串行请求；每个请求携带随机 request_id。

目前只支持 `hello`，返回源游戏身份、实际 rules/Host DLL 哈希、host_epoch、已加载参数包/行为/绑定/来源指纹和能力列表。启动默认加载嵌入参数包，也可传 `--parameters PACKAGE.json` 加载编译合同匹配的外部包；包不匹配会拒绝启动。`full_support=false`；simulate 等其他操作返回 `operation_not_implemented`，不回退旧引擎。

```powershell
& .runtime/tools/dotnet/dotnet.exe src/csharp/rules-host/bin/Release/net9.0/AutoSlay.RulesHost.dll --parameters src/csharp/rules/Generated/rule-parameters.json
```

同一数值包在进程启动时固定；更新后创建新 Host epoch，不能在旧 epoch 中悄悄改参数身份。

客户端可传 `expected_identity` 校验期望指纹；同一进程 epoch 内身份变化也会关闭进程并报错。4,000,000 字符上限、请求写入/读取共同超时、有界 stdout 缓冲、128 KiB 字符上限的 stderr 诊断、非法 JSON/重复字段/非有限数拒绝，都在客户端处理。超时只回收它自己创建的 Host。

这些文件不启动游戏、不部署 Bridge、不拥有真实动作权限。默认入口必须等完整迁移和方案切换门槛满足后整体切换。

## 世界克隆与当前检查点

`SimulationWorld` 持有自有模型、玩家、生物、有限 Run/Combat/Room/History 状态。RestorePlayer/Relic/Power 恢复观察，不运行获得/施加回调。命令通过世界 ExecuteAsync 上下文执行；并发复用、活动中 hydrate/clone、过期任务和失败分支复用会拒绝。

世界 `Clone()` 使用通用对象图复制私有字段，保留循环、别名、变量升级和 preview，并重连内部事件。它不调用原生 MutableClone；后者是新实体创建语义，Power 的内部数据和 owner 会被重置。后续迁入模型无需添加逐实体 RebindWorld。引用键字典/集合按自有对象身份重新散列，保留槽位和空闲链；未知布局、自定义键等同性/比较器和外部状态返回明确边界，不执行任意枚举器或键方法。

当前 `WorldSnapshotCodec.Export/Import` 对应 `contracts/rules-resource-snapshot.schema.json`，只支持有限自有资源/遗物检查点，绑定 rules DLL 与参数哈希。它保留变量的 base/enchanted/preview/upgrade、资源历史和轨迹，恢复不运行 AfterObtained；重复/未知字段、身份或变量形状错误会拒绝。Power、附加程序集和模型私有字段不能被该合同无损表达，因此明确拒绝导出；通用私有状态图 checkpoint 尚待实现。

完整 Run/Combat 全类别监听枚举尚未迁入。RestoreHookProjection 的显式顺序仅用于旧离线夹具，null 表示未知，不是生产完整性证明。Power 命令要求新的原生状态域观察，不能用该投影补齐缺口。

## Power 命令的当前范围

`PowerCmd` 已迁入 Apply 各重载、ModifyAmount、Decrement、TickDownDuration、Remove，以及给出/接收修正与 Before/After 通知。Artifact、Strength 的原始模型代码通过同一套命令执行，临时力量公共代码保留“移除自身后再施加到期变化”的顺序。Minion 的分类/死亡语义标记、共享 MultiplayerScalingModel 的绑定/公式也已有局部验证；这不包含完整死亡或回合末调度。

在自有世界恢复 `CombatHookObservation`，显式提供：

- allies/enemies 的顺序及每个生物的能力实例；
- 每个玩家的牌组、遗物、药水槽、PlayerCombatState 存在性、充能球和五个牌堆；
- run/combat 订阅者、modifier、badge 和共享缩放模型的存在性。

这些是状态域，不是效果绑定或回调白名单。Power/Relic/Card/Singleton 从自己的当前状态动态枚举；能力新增/移除和牌堆变化更新各自已知域。未观察的集合保持 null 并阻止依赖它的结算；目前未迁入的非空药水/充能球/怪物等域会报未实现，不当空集合处理。非空卡牌仅支持下文有限费用/牌堆范围，尚无原生卡牌完整认证。

恢复 round/side/玩家回合号，并明确恢复为空的 Power 接收历史后，才能执行会记录该历史的命令。`CombatHistoryEntry → PowerReceivedEntry` 保留历史引用环和回合判断；资源历史另有显式观察域，见下文。非空既有历史恢复及其余历史类别尚缺。正常早退无需强行提供后续不会读取的卡牌或历史。

`RestoreMultiplayerScaling(instanceId, attachedToCombat)` 建立原生 singleton 的自有 Run/Combat 绑定；按需显式恢复 act index 和 encounter 缺席状态。未知不会变成默认第 0 幕或普通遭遇。克隆会保留共享 singleton 身份关系并重连到新世界。

`RestoreLocalPlayer(netId)` 恢复每个世界自己的 LocalContext 身份；传 null 表示已知没有本地玩家，未调用表示未知。Power.IsVisible 沿用原生判断，不能把目标可见性当作无关 UI，因为 Artifact 会读取它。克隆隔离该上下文，不使用进程级可变静态身份。

`PlayerChoiceContext` 的模型栈和原生 Throwing 无选择上下文已迁入；后者遇到选择仍抛错，不是自动选择器。EncounterModel 仍只有分类且克隆拒绝；CardModel 已迁入有限费用/牌堆/标量变量/克隆成员，完整创建和出牌生命周期未闭合。实际卡牌来源、怪物、完整选择/随机/队列仍待迁入。当前纯显示等待被省略，不能把这些离线命令测试当作完整时序验收。

资源 checkpoint 会拒绝导出新增的状态域、时间线、历史、幕/遭遇/singleton，以及移除后仍被追踪的模型，避免静默丢状态。Host 仍仅 hello，默认预测尚未使用这些命令。机器报告和验证范围见[实施记录](游戏原生规则独立复刻实施记录.md)。

## 卡牌费用与能量的当前范围

CardEnergyCost 完整源码同步编译，保留顺序局部修改、reduceOnly、到期清理、费用升级/预览、X 捕获值，以及普通/晚期全局修正。CardModel 按原生构造签名和 owner/Pile/CombatState 结构提供相应上下文。Deck 和五个战斗牌堆从自有状态读取；低层 AddInternal/RemoveInternal 不代表完整的抽牌、弃牌、消耗、生成或打出命令。

`RestoreCombatHookInventory` 恢复玩家战斗存在性和牌堆域时只创建自有壳，能量仍未知。使用 `RestorePlayerEnergy` 显式恢复能量；非战斗可通过 `RestorePlayerCombatPresence(...ObservedAbsent)` 以及 `RestoreDeckCardInventory` 证明战斗状态缺席和牌组顺序。`RestoreCardCostScope` 需要显式费用状态和附魔/侵蚀缺席证明；恢复器只写自有编译费用类的四个固定字段，字段布局变化则报合同缺失，不接受任意字段名或行为程序。该 API 不是任意卡牌私有状态/已改 DynamicVar/完整出牌状态的恢复合同。

`PlayerCmd.GainEnergy/LoseEnergy/SetEnergy` 保留原生早退、修正/通知/最终增加的顺序及能量算术。NoEnergyGainPower 通过源码同步接入同一公共机制。星数与支付成员见下文；完整出牌、关键词消费者、附魔/侵蚀及其 StateTracker/RecalculateValues 消费者仍缺；PowerCmd 的非空 cardSource 仍拒绝。

当前运行包外置七条参数；符合直接字面量形态的构造费用、基础星数费用和升级增量已有通用抽取，其余间接、链式构造和其他成员尚未闭合，不能描述成所有实体改数值都已只需更新数据。卡牌/牌堆/费用/能量/星数/支付历史由通用世界克隆隔离，但有限 resource checkpoint 明确拒绝导出它们。Host 未开放费用或出牌模拟，生产入口未切换。

## 关键词与有限卡牌状态观察

CanonicalKeywords/LocalKeywords、AddKeyword/RemoveKeyword、KeywordSources 和全局修正按原生代码执行，创建新实体仅复制本地集合。全局贡献按当前监听顺序重新计算，源模型撤销后不固化在本地集合。原生关键词钩子使用原始 combat iterator，不套用费用的 Ending 门控；回调即使返回 false，集合修改仍生效。局部 Add/Remove 无实际变化也发送 KeywordsChanged 通知。

费用范围恢复后，本地关键词与升级等级仍未知；分别使用 `RestoreCardKeywords`、`RestoreCardUpgradeLevel` 提供明确观测，恢复不重放通知。空集合是明确已知为空，不回退 CanonicalKeywords；读取缺失状态时明确拒绝。Injury/Dazed 完整源类仅验证构造费用、原始关键词及有限状态，未认证 Unplayable 合法性检查、Ethereal 到期、自动消耗、完整升级或整张卡生命周期。相关消费者仍需迁入。

## 升级、变量与星数支付的当前范围

费用范围恢复还会将变量与星数状态标记为未知，分别使用 `RestoreCardDynamicVars`、`RestoreCardStarCosts` 完整恢复；它们不根据升级等级猜值。变量类型、集合、Props 和范围全部验证后再应用；星数状态保留原始 lazy/upgrade 标记、LastStarsSpent 与有序临时费用。`RestorePlayerStars` 仅恢复观察，不写历史、不触发获得通知。

CardModel 的 Upgrade/Finalize/Downgrade、CalculatedVar 的 owner/计算/升级重算，及 CardCmd 的升级/降级成员已按原生顺序实现。该范围要求附魔/侵蚀缺席；完整显示预览和专用计算变量仍缺。批量升级使用 `CardCmd.Upgrade(world, cards, style)` 显式传入上下文，保留 Ending 在枚举前返回的行为；原生无上下文重载仍缺。牌组升级/降级记录依赖明确为空的地图历史观察。Enlightenment 源回调已验证普通/升级版对手牌费用使用不同到期方式，完整出牌与 Exhaust 消费者尚缺。

星数 Gain/Lose/Set 命令保留许可、低层算术和通知顺序。星数变化历史使用实际截断后差值，获得通知使用请求量的整数部分；零获得仍通知。先恢复时间线、完整相关监听域，并调用 `RestoreEmptyCombatResourceHistory()` 明确资源历史为空，再执行需要记录历史的命令。它与 Power 历史观察互不代替；目前不能恢复既有非空历史，也没有全部历史类别的统一查询。

`PlayerCombatState.HasEnoughResourcesFor` 独立报告资源不足；`CardModel.SpendResources` 依次支付能量和星数，保留 X 捕获、每点超额能量换两颗星、历史/事件/回调顺序。支付不代替合法性验证；返回请求支付量可能大于实际扣除值。零能量支付仍调用 AfterEnergySpent；星数仅在正数支付时调用 AfterStarsSpent。失败回调使该分支不可复用，已发生前缀只保留在本分支。完整出牌包装及其支付调用方、关键词/牌堆消费者和 Host 模拟仍未接入。
