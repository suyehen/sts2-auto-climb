## 当前实际变更

- 增加 `contracts/game-models.schema.json` 和 manifest 的 `models` 数据集。`rules/model_store.py` 直接加载 JSON，校验版本/程序集、重复 ID、模型引用、变量绑定、操作、计数作用域、参数表达式等；错误标明实体和字段。嵌套数据只读，指纹随内容变化，知识快照及已返回的规则对象固定其版本。没有恢复 rulebook、审批晋级或逐实体许可。
- 原 Python 注册表中的 311 个实体全部迁入 JSON；删除旧实体字典和 `visible` 文案数值绑定。默认 `KnowledgeRules`、模拟、阶段/计数触发、规则查询及默认决策读取同一数据集；周期遗物不再在导入时复制实体配置。保留真实 DynamicVars，进入规范化计算后仍使用实例值，避免切回百科基础值。
- 增加会员卡价格修正声明，当前卡牌/遗物/药水共有 312 个声明。原 311 个迁移条目仍是 `migrated_requires_semantic_review`，不宣称已逐项对齐源码或完整交互验证。会员卡的 `source_reviewed` 也不等于全部交互已验收。
- `rules/resources.py` 让战斗和非战斗共用治疗、最大生命增加算术；`rules/run_commands.py` 提供资源支付、获得/失去、容量、牌组增删升级和顺序钩子。分支保存独立牌组、遗物、药水容量及库存、商店库存和轨迹。未知钩子进入 `gaps`，需要这些效果的完整排序保持未知。
- 路线删除燃烧之血固定 6 点回血回退和描述效果执行；通过公共胜利钩子处理回血，通过公共休息命令处理治疗。完整战略库存传入路线分支，死亡为吸收状态。损血情景和成长点仍是原有策略代理。
- 商店逐购买顺序克隆状态，实际改变金币、牌组、遗物、容量、库存；遗物先支付后获得，卡牌/药水先取得后支付。报价使用公开基础价格和 JSON 价格钩子；会员卡会改变分支后续价格。未知钩子停止该分支续算，不假造补货或后续动作 ID。
- 奖励/删牌/升级比较复用公共牌组命令；遗物选项复用 Obtain 及其获取效果。尚未接齐所有奖励、事件及宝箱的实际预测入口。
- 休息预测不再解析治疗文案；读取实际治疗量，或使用同一 JSON 基础参数及已定义修正。SmithCount 驱动有预算的多张升级组合。Bridge 开放本版本九类实际休息选项的原有回调，导出模型类型、修正后治疗量及 SmithCount；Cook 的已观察选牌后续已有合同；其他选项的完整预测仍保持未知。
- Bridge 的变量导出保留完整类型、泛型参数、变量类型的模型引用、Base/Enchanted/Preview 值及 ValueProp，明确变量引用不等于实际效果引用；百科增加完整 ModelDb 类型清单导出代码。商店补充基础价格和实例动态变量。代码已编译，但尚未部署或重新导出本地百科。
- 事件统一走 `rules/flows.py` 的声明式状态机，删除原 Bath/Flower/Tablet 的 Python 专用算法、运行期源码调用解释和文案效果执行。五个 JSON 流程为 AbyssalBaths、ColossalFlower、TabletOfTruth、TheLanternKey、DenseVegetation；当前页绑定公开变量、计数及稳定选项键，新 Bridge 同时导出实际回调和来源类型并校验。随机升级按真实池等概率分支并更新后续池；伤害持续增加不从封顶页计数推测。
