# 战斗决策数学模型共建草案

状态：讨论稿 v0.1 · 建立日期：2026-10-18

本文用于共同确定数学模型，再据此安排实现和验证。下文的“建议”均未确认为最终设计，也未修改运行配置。当前行为依据源码与仓库默认配置整理；本机覆盖配置和运行中实际参数应在实验归档时另外记录。

## 1. 我们要解决什么问题

希望战斗决策能够在有限计算时间内，选择更有利于整局推进的动作，并解释收益、风险与估计误差。先围绕四个问题讨论：

1. 这次出牌最终希望保住什么：整局存活、生命、药水、永久成长，分别如何取舍？
2. 两回合后尚未结束的战斗，怎样估计剩余代价？
3. 怎样区分真实随机风险、采样不足和机制未建模？
4. 怎样确保候选之间的比较没有被搜索顺序、预算分配和估计深度主导？

现有动作模拟、合法性校验、观察后重规划和逐步执行校验可作为基础继续使用。算法改动的效果需要实验确认，本文列出的结构性风险不等于已经测得的实战缺陷。

### 1.1 第一轮讨论表

| 编号 | 要决定的事项 | 当前建议 | 状态 |
| --- | --- | --- | --- |
| D01 | 优化目标 | 以整局继续价值为方向，先实现“生存约束下的战后资源价值”代理 | 待讨论 |
| D02 | 风险偏好 | 比较“死亡风险优先”与“风险预算内最大化收益”；暂不预设可接受死亡率 | 待讨论 |
| D03 | 截断价值 | 先做短程合法续打估值，再考虑训练小型价值模型 | 待讨论 |

推荐先讨论 D01、D02、D03；其余模型应服从这三项决定。

## 2. 当前模型的基线

### 2.1 实际决策路径与配置

仓库默认开启 `combat_batches_enabled`，`strategy_mode` 为 `off`。主要路径是生成操作批次、模拟候选终点、假想后续动作与随机分支、评分、选择批次，在实际观察边界重新规划。

| 项目 | 默认值或当前实现 |
| --- | --- |
| 预测范围 | 当前及下一玩家回合，`horizon=2` |
| 抽牌分支上限 | 32；结果较少时精确枚举，较多时采样 |
| 普通预算 | 2000 节点、搜索预算 200 ms |
| 危险预算 | 6000 节点、搜索预算 400 ms |
| 批次最大长度 | `SearchBudget.max_depth=6` |
| 假想回合内动作深度 | `min(5, max_depth)`；下一玩家回合重置深度 |
| 下一回合基础资源 | 5 张牌、3 点能量，叠加已覆盖的周期遗物 |
| 候选初排 | 预计死亡指标升序、分数降序，再比较近似数量等 |
| 接近方案决胜 | Top-K 内死亡指标相同、分差 ≤1，优先少耗药，再比较最坏净失血等 |

上述时间是算法内检查的搜索预算，不等于完整分析请求的墙钟耗时上限。5 张牌、3 点能量也是当前预测参数，不能视为所有局面的真实资源。

`combat_value.py` 中的独立短期效用模型与当前批次终点评分不是同一套实现。批次路径读取 `batch` 参数、药水参数及 `short_term.finish_weight` 等；例如 `short_term.discount=0.9` 并未作为整个批次评分的统一折扣。实验必须注明具体入口和生效参数。

### 2.2 当前生命效用

令 $h$ 为生命，$M$ 为最大生命，$\theta$ 为保留血线，$r$ 为休息机会权重，$(x)_+=\max(0,x)$。当前函数是：

$$
U_{HP}(h)=w\left[h-\beta\frac{(M-h)^3}{3M^2}\right]
-r\frac{(\theta-h)_+}{\max(1,\theta)}.
$$

默认 $w=2$、$\beta=3$。保留血线和休息权重由未来四步内可达的休息点、精英及 Boss 修正。

在阈值以外，生命的边际价值为：

$$
U'_{HP}(h)=w\left[1+\beta\frac{(M-h)^2}{M^2}\right]
+\mathbf1_{h<\theta}\frac{r}{\max(1,\theta)}.
$$

因此低血量的一点生命本来就更值钱。后续改动应保留这项能力作为基线，并验证它与新增风险项是否重复强化保守倾向。

当前生命分项按候选状态相对初始状态计算；胜利时两边都加入封顶的战后回血。例如燃烧之血会同时作用于候选和基线，避免将固定回血理解为可以无代价掉血。胜利与未胜利状态采用不同回血处理，统一价值模型时还需要统一比较基准。

### 2.3 当前批次终点分数

将代码中的分项写成简化形式：

$$
S=\Delta U_{HP}+\widehat C_{future}
+50\mathbf1_{win}-0.4\sum_i HP_i
-N_{pollution}-C_{potion}-3N_{unknown}
-10000\mathbf1_{dead}.
$$

其中敌方剩余生命只统计仍存活的敌人；胜利时该项为零。污染项按牌堆标识中匹配的状态牌数量计数。`enemy_growth` 与 `player_growth` 分项当前为零，部分成长价值通过未来压力代理间接体现。实际分支合并还会产生近似计数，报告的 `approximation_count` 并不总能直接乘 3 还原未知惩罚。

未来压力代理近似为：

$$
u=\min\left(1,\frac{3}{\max(1,5\bar c)}\right),\qquad
D=\max\left(1,5u(\bar d+STR\cdot\bar k)\right),\qquad B=5u\bar b,
$$

$$
\widehat T=\min\left(4,\frac{\sum_i(HP_i+Block_i)}{D}\right),\qquad
\widehat L=(I-B)_+\widehat T,
$$

$$
\widehat C_{future}=0.5\left[U_{HP}(\max(0,h-\widehat L))-U_{HP}(h)\right].
$$

$\bar c,\bar d,\bar k,\bar b$ 分别是牌组平均费用、伤害、攻击段数和格挡；$I$ 是存活敌人的攻击总量。虚弱、脆弱会进一步修正输出与防御。终点敌人全部没有攻击时，代码还会尝试推演一次已知非攻击招式，用其后续攻击计算压力。

### 2.4 当前随机分支与排序

对于分支权重 $p_j$ 和分支结果，当前合并近似为：

$$
\bar S=\frac{\sum_jp_jS_j}{\sum_jp_j},\qquad
\widehat p_{death}=\frac{\sum_jp_jd_j}{\sum_jp_j},\qquad
L_{worst}=\max_j L_j.
$$

未知分支会使用近似续算，采样分支使用经验频率。排序首先最小化 $\widehat p_{death}$，再最大化 $\bar S$；因此死亡惩罚与死亡优先排序目前同时存在。

耗药成本在分支分数中按概率平均，但 `consumed_potions` 合并为所有分支用药的并集，接近方案决胜时按这个集合的大小比较。这两种消费口径需要区分。

## 3. 建议的统一建模语言

### 3.1 状态、观测与动作

| 符号 | 含义 |
| --- | --- |
| $s_t$ | 玩家生命、费用资源、手牌、各牌堆、能力、遗物计数、敌人状态和历史等 |
| $o_t$ | 当前实际可见的观测 |
| $b_t$ | 隐藏抽牌顺序、尚未确定的敌人分支等的条件分布 |
| $a_t$ | 当前合法动作，或执行至观察边界的确定性动作前缀 |
| $\pi$ | 随已观测历史变化的后续策略 |
| $\omega$ | 一条抽牌、敌人动作等随机情景 |
| $H$ | 预测截止范围，需要明确按玩家回合还是动作计数 |
| $T$ | 战斗结束时刻 |
| $z_T$ | 战后生命、药水、金币、永久成长、遗物计数、路线位置等资源 |

当前“牌堆组成＋无放回抽牌分布”已包含部分信念状态表达，不必先重写成通用 POMDP 框架。需要明确各类随机假设，并补充会影响分布的已知顶牌、保留、洗牌、费用修饰等机制。

后续策略只能依赖当时已观察的信息。同一段可见历史下不能因为模拟器知道未来抽牌而提前选择不同动作；抽牌已经揭示后允许各分支作不同选择。现有抽牌后分支续算与实际停下观察的结构可以保留。

### 3.2 候选目标：整局价值的战后资源代理

长期方向可以是最大化整局通关概率，但当前缺少足以将启发式分数解释为通关概率的数据。第一版建议采用明确的资源效用代理 $V_{run}(z)$，保留其“代理分数”的身份。

统一终点为：

$$
V_{end}(s)=
\begin{cases}
-C_{death}, & \text{玩家死亡};\\
V_{run}(z(s)), & \text{存活且战斗结束};\\
\widehat V_{continue}(s), & \text{战斗尚未结束}.
\end{cases}
$$

其中 $\widehat V_{continue}$ 预测的是“从该状态继续作决策后的终局价值”，与前两项采用相同单位。它包括后续可能死亡的结果，不能只计算剩余平均掉血。

对 $\tau=\min(H,T)$，在固定后续策略 $\pi$ 下：

$$
Q_H^{\pi}(s,a)=\mathbb E\left[V_{end}(s_\tau)\mid s,a,\pi\right]-V_{ref}(s).
$$

$V_{ref}(s)$ 对当前所有候选相同，只用于方便阅读相对收益。搜索在有限预算内近似寻找较好的 $\pi$，不能将这个结果标为精确最优值。

首版建议 $\gamma=1$。只有在明确希望给时间本身定价时，才引入折扣或回合成本；战斗拖长造成的实际掉血、敌人成长已经由转移模型体现。永久成长、金币或遗物蓄能带来的延长战斗收益，应显式建模并检查终止条件。

### 3.3 统一账本规则

| 资源或效果 | 建议记账位置 | 需要避免的重复 |
| --- | --- | --- |
| 当前与未来失血、回血 | 状态转移改变生命，终点评估生命价值 | 既按终点生命扣分，又重复扣同一段失血 |
| 战后回血 | 进入战后状态时结算并封顶 | 每个预测回合重复回血 |
| 用药 | 状态移除药水，最终库存价值变化 | 扣库存价值后再扣一次同一保留成本 |
| 持续力量、抽牌引擎 | 影响后续合法行动与终点价值 | 完整续打已算收益，再追加固定成长奖励 |
| 击杀、战斗胜利 | 敌方转移消失，进入战后资源状态 | 剩余代价已消失又重复计一份避伤收益 |
| 风险偏好 | 显式风险规则，单独报告 | 将风险惩罚伪装成实际生命损失 |

如果采用逐步资源奖励，也可以构建一致的价值函数；但应明确使用差分奖励和剩余价值，不能与全量终点资源价值重复相加。迁移时保留旧分项作诊断，不直接把新旧全部叠加。

## 4. 截断价值：从平均能力到可实现的后续结果

### 4.1 需要验证的偏差

1. 整副牌的平均值不能充分反映当前抽牌堆与弃牌堆的差异，也不能反映消耗后的有效循环。
2. 费用平均折算允许“分数张牌”，会高估部分手牌下同时攻防的能力。
3. 敌方总血量相同，不代表后续威胁相同；击杀高威胁目标、触发阶段切换或召唤会改变代价。
4. 固定胜利奖励可能放大恰好跨过预测截止点的差别。
5. 成长牌的收益可能落在第三回合以后，当前尾部代理难以区分不同引擎的启动时间。

示例：3 点能量，手里是两张 2 费牌，一张造成 14 伤害，一张获得 14 格挡。将总费用 4 按 3/4 缩放，会给出 10.5 伤害与 10.5 格挡；这个状态实际上不可通过正常出牌实现。它是平均折算的示意反例，并非声称当前每条候选都按此方式模拟。

### 4.2 方案 T1：有界合法续打估值

从截断状态抽取或枚举若干合法随机情景，使用便宜但可执行的后续策略续打。每条轨迹得到战后资源与死亡结果，仍未结束的轨迹再使用更轻量的残值估计。

$$
\widehat V_{continue}(s)=\sum_j p_j\,\widehat V_{end}^{\pi_{cheap}}(s;\omega_j).
$$

“先揭示手牌，再在该手牌的合法序列中选择”的期望，能表达能量竞争和组合。若每张手牌单独最优，结果是给定后续估值下的有限搜索结果；若使用廉价策略，则明确记录策略身份与近似误差。

建议先试 T1：复用现有模拟器，按预测跨度与剩余预算设上限，保留最终资源分布，并对同类状态缓存。价值缓存必须包含相关牌堆、怪物历史、计数、模型和策略版本。

### 4.3 方案 T2：学习终点价值

数据足够后，比较线性模型、广义加性模型或小型树模型。输入包括实际牌堆分布、可用费用、持续能力、关键组合到达时间、敌人阶段、药水和路线信息。

输出优先拆成可验证的量：战斗结束概率、死亡概率、战后生命和耗药分布，再按共同效用组合；也可同时预测效用用于对照。

高预算同模型续打适合产生老师标签，但会继承模拟器错误。它只能验证计算近似，不能独立证明真实机制或实战收益。模型以整局划分训练与验证，另用真实轨迹核对机制和预测校准。

### 4.4 本模块的讨论与验收

待决定：优先 T1 还是 T2、额外预测预算、哪些状态应延长预测，以及永久成长是否进入第一版。

验证局面：两回合快杀与三回合低损结束；力量牌先启动；关键牌在抽牌堆或弃牌堆；已消耗大量基础牌；相同总血量但威胁分布不同的多敌人。

记录 $H=1,2,3$ 及更长参考续打下的选择变化和后悔值。更长预测与更大搜索空间相互影响，应另外固定节点或计算量，不能把所有变化归因于终点价值。

## 5. 风险与不确定性

### 5.1 三类不确定性分开记录

| 类型 | 示例 | 对应方法 |
| --- | --- | --- |
| 游戏随机性 | 抽牌、按已知权重选择招式 | 精确概率分支或正确采样 |
| 计算误差 | 样本少、搜索未覆盖、截止估值不准 | 增算、配对评估、独立误差测量 |
| 模型误差 | 未覆盖遗物、招式或触发顺序 | 补机制、多情景、带来源的误差范围 |

增加抽牌样本不能修复漏算的遗物。固定未知扣分也不等于风险概率或置信区间。

### 5.2 保留分布

建议每个候选输出可加权的结果样本或直方图：死亡、终局效用、生命损失、药水消费、战斗是否结束、残值来源，以及精确枚举/采样身份。

精确权重保留原始概率质量；采样保留原始样本数、重复次数、随机源和是否自适应选样。混合树的叶子数不能直接当作独立样本数。未知质量单独标注或由明确情景覆盖，不能静默归一化后宣称完整概率。

例如，对固定策略在正确模型下独立采样 32 次，零次死亡时的单侧 95% 二项上界是：

$$
1-0.05^{1/32}\approx 8.9\%.
$$

这个例子不适用于直接给当前自适应搜索树出具保证；同一批样本既选策略又评估策略会产生选择偏差。可以使用独立评估样本，或采用适合序贯选择的统计方法。

### 5.3 风险规则的候选方案

| 方案 | 定义 | 优点 | 主要问题 |
| --- | --- | --- | --- |
| R1 | 先最小化死亡风险，再最大化资源价值 | 接近当前行为，易解释 | 微小估计差异可能压倒全部资源收益 |
| R2 | 在死亡风险预算内最大化资源价值 | 明确表达可接受风险 | 需要决定预算，并解释概率上界的证据来源 |
| R3 | 统一期望效用，死亡为明确终局代价 | 目标函数统一 | 死亡代价与资源尺度需要校准 |

建议把 R1 作为基线，重点比较 R2；不在讨论前填入一个任意可接受死亡率。

R2 的形式是：

$$
\max_a\mathbb E[U_a]\quad\text{s.t.}\quad
\overline p_{death}(a)\le\varepsilon.
$$

若所有候选均不满足约束，选择证据可比条件下风险最小的候选，并报告约束不可满足。没有足够证据计算上界时，记录“上界未知”，采用明确的模型情景或降级策略，不能把未知当作零。

局部死亡率需注明预测范围：当前回合、完整战斗或整局。两回合风险低不代表整场安全；整局风险目标也不能简单对每场使用同一个预算。若以后分配风险预算，可用条件风险与保守的累计约束，但需考虑遭遇数和路线变化。

### 5.4 可选的尾部损失项

若平均资源收益仍无法表达偏好，可增加尾部损失。设 $L$ 为相对固定参考资源价值的非负损失：

$$
\mathrm{CVaR}_{\alpha}(L)=\min_{\eta}\left[
\eta+\frac{1}{1-\alpha}\mathbb E[(L-\eta)_+]
\right].
$$

候选目标可以是 $\mathbb E[U]-\lambda\mathrm{CVaR}_{\alpha}(L)$。它度量最差一部分结果的平均损失，比“样本最大失血”更容易表达稳定的风险偏好。

是否加入、$\alpha$ 与 $\lambda$ 都待讨论。首轮可设 $\lambda=0$ 单独验证其他改动；少量样本难以估计极端尾部。例如 32 个等权样本在 $\alpha=0.95$ 时，尾部只相当于 1.6 个样本。非线性生命效用、死亡惩罚与 CVaR 也需要联合检查，避免无意叠加过强的保守倾向。

若每个树节点都重新计算风险目标，还需明确“嵌套风险”还是“从本次根节点看整条轨迹的风险”，两者一般不等价。第一版可在根节点对固定续打策略的整条结果分布比较，记录实际重规划带来的差异。

## 6. 生命、药水与整局资源

### 6.1 生命价值

先保留第 2.2 节函数，单独研究 $w,\beta,\theta,r$。实验问题是“在具体路线与牌组下，为避免少量失血值得消耗多少资源”，而非只看公式是否平滑。

对随机血量，应计算 $\mathbb E[U_{HP}(h)]$，通常不能用 $U_{HP}(\mathbb E[h])$ 替代。最大生命增加也需要作为独立状态变化，不能仅用当下回复量近似。

地图上下文需来自可行的同一条路线或明确的路线分布。当前可达节点中的最近休息点与最大精英压力可能属于不同分支，后续应避免将互斥路线拼成一个虚构未来。

### 6.2 药水的边际价值

$$
C_p(z)=V_{run}(z\text{，持有药水 }p)
-V_{run}(z\text{，移除药水 }p).
$$

该价值应取决于当前血线、牌组短板、下一场威胁、替代药水、空槽、补充机会和距离终局的长度。未来掉落概率只能来自明确的规则或统计假设，不能当作已知奖励。

库存整体定价可以表达两瓶药水的替代性或互补性。多瓶同时使用时应比较库存集合价值，或按明确顺序计算条件边际值；直接相加各瓶在原库存上的边际值可能重复计价。

在完整库存价值尚未实现时，保留成本可以继续作为代理，但必须与生命分数使用同一效用尺度，并进行上下界敏感性分析。不得把整个区间的中点称为已经校准的真实价值。

### 6.3 随机分支的用药

令 $n_p(\omega)$ 表示分支中的用药数量：

$$
\mathbb E[N_{potion}]=\sum_jp_j\sum_pn_p(\omega_j).
$$

报告至少区分本次实际批次必用、假想后续可能使用、期望用量与最坏用量。分支并集仍可用来说明“可能涉及哪些药水”，不宜单独代表消耗成本。

## 7. 搜索与采样预算

### 7.1 当前问题与改造方向

当前批次先广度优先生成终点、去重，再按可模拟性与批次长度等排序评估；所有候选共享后续搜索预算，预算耗尽时调用快速评价。候选补回机制保证部分首步被代表，但不保证各候选获得相同深度的评价。

建议按以下过程实验：

1. 在有界生成阶段为合法首步建立代表候选，记录未覆盖者；同一首步下保留不同战术终点。
2. 每个代表候选获得相同口径的最低粗评预算。
3. 按估计差距和不确定性，对有机会胜出的候选追加计算。
4. 对最终入围方案使用独立或配对场景复评，并报告未解决的分差。

可借鉴最佳臂识别、逐轮淘汰和序贯采样，但“统计淘汰”只有在相应误差区间成立时才有效。启发式上下界应标为启发式，不能据此宣称证明最优。

### 7.2 配对随机场景

对候选 $a,b$，比较：

$$
\widehat\Delta(a,b)=\frac1N\sum_{j=1}^N
\left[U(a,\omega_j)-U(b,\omega_j)\right].
$$

共同随机源有机会降低差值方差，但必须保证每个候选自身的边际分布正确。不同方案改变牌堆或抽牌数量时，不能直接强行给它们相同手牌；应设计与各自牌堆一致的随机耦合，并测量实际降方差效果。只设置相同整数种子并不自动满足这些要求。

### 7.3 去重与可比性

确定性地到达同一完整状态、且没有新的观察信息时，可以共享后续价值计算；同时保留不同前缀的来源、已消耗资源和执行边界。不同观察信息、待恢复效果或相关历史不能误合并。

预算统计至少包括每个候选的节点数、完整续打数、深度、快速估值次数、采样数和缓存命中。验证时同时比较固定节点预算与固定墙钟预算，区分算法质量和机器耗时差异。

## 8. 数据、实验与验收

### 8.1 分开测量四类误差

| 误差 | 对照方式 | 解释边界 |
| --- | --- | --- |
| 机制误差 | 一步预测与实际结果逐字段核对 | 未观测反事实不能由日志凭空补出 |
| 搜索误差 | 相同模型与效用，低预算对高预算/小局面穷举 | 高预算未必全局最优 |
| 采样误差 | 小分布精确枚举；大分布多随机种子与独立评估 | 同一批样本选优后会有乐观偏差 |
| 终点误差 | 固定中间状态，短期残值对更长续打及独立实测 | 同模拟器续打不能验证自身机制 |

这些误差会相互影响，未经证明不简单相加成正式总误差上界。

### 8.2 评价指标

主要策略指标为参考后悔值：

$$
Regret(s)=\max_{a\in\mathcal A_{ref}}Q_{ref}(s,a)
-Q_{ref}(s,a_{chosen}).
$$

参考必须使用同一个已确定目标及风险口径。如果参考未覆盖所有可比动作，报告为“已覆盖参考集上的收益差”，不能当作真实最优后悔值。相同首步不同后续策略也要说明比较范围。

同时记录平均与高分位失血、死亡概率校准、误判安全的比例、期望耗药、战斗与整局结果、不同种子和候选顺序下的排名变化，以及计算耗时。Brier 分数、可靠性图等概率指标需要足量独立结果，稀有死亡事件不能仅凭少数样本判定校准良好。

### 8.3 首批局面矩阵

| 场景 | 主要检查内容 |
| --- | --- |
| 两回合快杀 / 三回合低损结束 | 截断与胜利奖励偏差 |
| 低血量抽牌，存在坏手牌 | 死亡尾部与样本不足 |
| 3 能量、两张 2 费攻防牌 | 能量竞争与不可实现的平均状态 |
| 力量或抽牌引擎启动 | 成长价值与剩余战斗长度 |
| 同牌组、不同牌堆分布 | 牌堆条件信息是否进入估值 |
| 同总血量、不同敌人威胁 | 目标选择与怪物阶段 |
| 药水仅在少数分支使用 | 概率成本与分支并集的差异 |
| 战后回血接近满血 | 封顶、共同基准与重复记账 |
| 未建模能力会改变结果 | 模型未知与游戏随机性的区分 |
| 打乱动作 ID / 枚举顺序 | 搜索顺序偏差 |
| 互斥地图分支的休息点与精英 | 路线条件一致性 |

### 8.4 数据划分与实验纪律

同一整局的状态放在同一分区；若多个对局共享生成种子或高度相似来源，应按来源分组避免泄漏。开发集用于选择结构与参数，校准集用于误差和概率校准，保留集只做最终评价。

每次实验保存状态、游戏/规则/代码/配置身份、候选集合、随机种子、后续策略、预算、参考来源和结果。普通历史选择只说明当时做了什么，不能直接作为最优动作标签。

先做单项消融，再测组合：公平预算、终点价值、风险规则、药水价值分别与同一基线比较。预先固定主要指标及可接受的退化范围；具体阈值由基线分布和样本量决定，当前不虚构通过标准或实战提升比例。

## 9. 建议的实施顺序

| 阶段 | 交付内容 | 进入下一阶段前要回答的问题 |

| P3 改进风险决策 | R1/R2 对照、概率证据身份、自适应采样；CVaR 可单独试验 | 风险偏好是否符合预期，估计是否可信？ |

每阶段先产出可回放、可比较的报告，再决定是否切换默认策略。实现开关应对应模型版本，避免不清楚某次效果来自哪个组合。
