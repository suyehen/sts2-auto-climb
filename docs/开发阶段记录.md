# AutoSlayTheSpire

工作台「Agent 管理」支持标准配置导出、含密钥的密码加密导出、旧版配置迁移和本地备份恢复；仅处理业务配置，不包含对局数据。见 [配置导入导出与版本迁移](docs/配置导入导出与版本迁移.md)。

当前入口：双击 `launch/start_agent.cmd`。百科支持职业／来源、稀有度与卡牌类型筛选，基础／升级效果切换，以及本地游戏卡面。源码目录与更新方法见 [目录规范与百科分类](docs/目录规范与百科分类.md)。

## 环境

- Anaconda 项目环境：`.runtime/conda`，Python 3.12。
- 项目内 SDK：`.runtime/tools/dotnet`，.NET 9。
- 模组：`src/csharp/bridge/`，适配本机 v0.111.0，纯代码 DLL，无需编辑器资源打包。
- MCP 接入：`src/python/src/autoslay/mcp/`，已注册为 `autoslay`。

## Agent 与模型后端

运行 `launch/start_agent.cmd` 启动 Agent、观察台与实时侧窗，默认暂停。两个视图均提供后端选择、“切换并暂停”、模型配置和当前局自动游玩入口。支持本机 Codex 登录、DeepSeek、其他 OpenAI 兼容云端 API，以及 Ollama / LM Studio / vLLM 的本地兼容接口。

首次默认 DeepSeek，需在本地填写密钥；切换不会自动开始游戏。详细配置、密钥存储及当前验证范围见 [Agent 后端切换与配置](docs/Agent后端切换与配置.md)。Agent 代码位于 `src/python/src/autoslay/agent/`，独立于 MCP、数学模型和百科。

## 功能目录

根目录按用途保留 `src/`、`launch/`、`scripts/`、`contracts/`、`config/`、`data/`、`docs/`、`.runtime/`。环境、SDK、缓存和本机配置集中在 `.runtime/`；Python 依赖配置在 `src/python/`；.NET 构建配置在 `src/csharp/`。

| 目录 | 职责 |
|---|---|
| `src/csharp/` | C# 模组、游戏状态读取、程序集检查工具 |
| `src/python/src/autoslay/mcp/` | MCP 服务入口和工具定义 |
| `src/python/src/autoslay/bridge/` | Python 游戏接口客户端 |
| `src/python/src/autoslay/execution/` | 常驻通信、明确动作序列、状态校验与台账 |
| `src/python/src/autoslay/knowledge_base/` | 后续知识检索和 RAG 实现 |
| `src/python/src/autoslay/analysis/` | 后续牌组分析和计算 |
| `src/python/tests/` | Python 与 MCP 集成测试 |
| `data/knowledge/` | 后续版本化知识数据 |
| `contracts/` | 后续跨语言协议定义 |
| `launch/` | 用户日常启动入口 |
| `scripts/` | PowerShell 构建、部署、测试和游戏重启 |
| `src/python/tools/` | 按用途归档的 Python 命令行工具 |
| `src/web/` | 网页资源、模块与前端测试 |

MCP 接入层调用 Python 核心模块；核心模块不依赖 MCP。知识数据与检索代码分开维护。预留目录不代表对应功能已实现。

## 本地百科

已支持本地百科查询与显式刷新，见 [百科资料库](docs/百科资料库.md)。数据位于 `data/knowledge/catalog/`，MCP 查询入口为 `query_encyclopedia`，更新入口为 `refresh_encyclopedia`。百科说明与可执行计算规则分别维护。

抽牌容量、生成牌溢出、无法抽牌和周期遗物联合时机评估见 [抽牌机制与遗物时机](docs/抽牌机制与遗物时机.md)。持久机制库在 `data/knowledge/mechanics/`，入口 `query_game_mechanics`；独立遗物时机权重在 `config/decision/relic-timing.default.json`。普通战斗不进行卡计数搜索，多个遗物按实际计数联合评估。
# 全量知识规则与决策面板

详细进度见 [实施记录](docs/全量知识规则与决策面板实施记录.md)。本地只读面板地址为 `http://127.0.0.1:18767/`，源码位于 `src/web/public/`。支持完整状态、逐步转移、评分分解、概率、AI/执行证据、历史和回放。百科更新、规则兼容检查、连续事件与自动策略扩展接口已加入；**全量机制适配仍未完成**，不能将资料导出或参考兼容数当作完整计算支持。

观察台现支持每 2 秒实时跟随，以及本局 → 动态幕次 → 地图节点 → 完整时间线浏览。各幕地图分别保留，未读取地图不补造；桥接 0.23.0 加入跨重启的存档身份。详细用法和验证范围见 [实时决策观察台](docs/实时决策观察台.md)。218 项 Python/MCP/HTTP 回归通过，四幕界面交互已用隔离数据验证；整局游玩链路仍待下一次实测。

双窗口与逐局归档已实现：双击 `launch/start_observer.cmd` 打开独立实时侧窗，`launch/start_history.cmd` 用系统默认浏览器打开历史总览。实战数据保存到 `data/runs/YYYY-MM-DD/run_<ID>/`，支持日期筛选、动态幕地图、到访尝试、完整报告、归档包导入导出和旧记录复制迁移。实现、启动与验证范围见 [双窗口实施与使用](docs/观察台双窗口实施与使用.md)。桥接 0.24.0 已部署并验证主菜单连接和暂停状态；整局真实游玩验收仍待进行。
