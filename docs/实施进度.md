## 环境与代码

- 项目使用 Anaconda 创建的 `.runtime/conda` 环境，Python 3.12；未向全局 Python 安装依赖。
- .NET 9 SDK 安装在 `.runtime/tools/dotnet`，安装包按微软发布元数据校验 SHA512。
- `src/python/` 下的 `environment.yml` 定义 Conda 环境；`pyproject.toml` 定义 Python 依赖；`requirements.lock.txt` 记录本次安装版本。
- 桥接位于 `src/csharp/`，是纯代码 DLL，直接引用本机游戏程序集，当前不需要 MegaDot 编辑器或 BaseLib。
- 当前适配游戏 v0.111.0，路径 `E:\steam\steamapps\common\Slay the Spire 2`。

## P0 范围

提供只读状态，包括玩家、牌组、手牌、费用、敌人血量与意图。HTTP 监听回环地址，访问使用本地凭据；HTTP 线程只读取主线程生成的 JSON 快照。

此版本没有动作接口，`ready=false` 表示尚不支持可决策时刻检测。快照可能处于结算过程中，不能据此宣称稳定决策点已经实现。多人、隐藏意图机制和各种子界面需要后续逐项核对。

MCP 提供 `get_state` 和 `get_installation_info`，通过项目 Conda 环境运行。游戏未开启时返回明确的连接状态。

```powershell
./scripts/build/Build-Bridge.ps1
./scripts/build/Deploy-Bridge.ps1

```
