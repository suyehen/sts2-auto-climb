# 对局记录

记录按地图节点、战斗回合、单次决策展示。每次决策内部区分分析与计算、所选动作、执行与结果；状态快照默认折叠。奖励、地图行进等放在回合外的独立区域。界面删除记录类型与到访筛选，不展示“第一次到访”或“分段”。原始档案及其中的内部关联字段不改写。

决策通过分析 ID、模型计划请求 ID 和动作请求 ID 关联。同一 AI 计划的多步动作属于一次决策，结束回合后的执行结果仍归原始回合。本地规则与 AI 选择分别标注；只有请求档案时显示“已请求 AI，未记录返回”，不会假称已收到 AI 决策。使用同一缓存分析的不同模型请求保持不同决策组，避免重复启动和重试被混为一次。

地图资源由 `src/python/tools/knowledge/export_map_icons.py` 从本机游戏包导出，保留图集区域、透明边距及原像素，并保存来源和校验值。网页不再使用手绘替代图标。导出的 SVG 内嵌图片，不依赖后续服务在线。

桥接新增只读 `icon_asset`：读取游戏实际分配的纹理，支持已揭示问号节点、远古之民和静态首领；纹理未提供资源路径时，从对应游戏模型取得路径。此字段需要加载新桥接后采集。

旧地图可通过 `backfill_map_icons.py` 补齐：读取本机当前存档，严格核对对局开始时间、全部节点坐标、类型和连线，再将原生图片关联写入独立的 `map_artwork` 元数据。原始快照和地图记录不修改。后续地图归档也会尝试此校验；展示仅接受与原地图摘要匹配的元数据。当前对局的涅奥和同族已补齐，不需要重启游戏。身份无法核实或 Spine 动画首领没有单张纹理时，仍显示名称，不猜测或使用其他首领图标。
